FAQ

Otázky pred nákupom.

Je počítač pripravený na použitie?

Áno, pri produktoch je uvedený operačný systém a počítač má byť pred odoslaním skontrolovaný a pripravený.

Dostanem presne tento kus?

Produkty sú vedené ako skladové kusy. Pri objednávke sa rieši konkrétny model alebo konfigurácia uvedená v karte.

Ako funguje admin na GitHub Pages?

Admin ukladá zmeny lokálne. Pre verejný web treba stiahnuť nový product-data.js a nahrať ho na GitHub.

Je heslo v statickom admine bezpečné?

Nie je to plná bezpečnosť. Pre veľký ostrý predaj treba backend, napríklad Supabase autentifikáciu.
