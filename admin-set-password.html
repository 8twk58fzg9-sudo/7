Nastaviť admin heslo

Vygeneruje bezpečný hash vášho hesla (PBKDF2, 150 000 iterácií). Heslo sa nikam neposiela — všetko prebieha vo vašom prehliadači.

  1. Otvorte config.js.
  2. Nájdite riadok ADMIN_PASSWORD_HASH: ''.
  3. Nahraďte ho skopírovaným riadkom a uložte.
  4. Nasadte web. Odteraz platí nové heslo.
